**Countries Edu**

An interactive educational world map web app that lets users explore countries, view real time data, and learn geography in a fun way.

---

**Features**

- Interactive SVG world map

- Detailed country information panel
  - Capital city
  - Area
  - Currency
  - Languages
  - Flag
- Smooth zoom in and zoom out controls
- Fullscreen mode 
- Light / Dark mode toggle

---

**Live Interaction**

Click any country on the map to:

- Open side information panel
- See flag and details instantly

---

**languages used:**

- HTML
- CSS
- JavaScript
